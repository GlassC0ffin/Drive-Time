# System Charter

**Constraints:**
1. No external libraries in the template — pure Canvas only.
2. One signal in, one parameter driven, no exceptions.
3. Every AI-generated block gets a plain-language explanation before it's committed.

**Tensions:**
- Order vs. chaos: the loop should feel predictable enough to trust, unpredictable enough to watch.
- Signal vs. noise: the one input matters; everything else is discarded.
